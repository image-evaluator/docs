# 成对保真度评估

成对图像保真度评估体系面向具有配对基准真值（参考图）的图像生成、超分辨率重建、图像修复与去噪编辑任务。本套件集成了三大互补指标：学习感知图像块相似度、结构相似性指数与峰值信噪比，从深度特征抽象语义、局部结构统计特性以及底层像素能量重构三个不同层次，建立多尺度保真度量化基准。

## 三重视角与语义互补性

生成图像与参考图像的差异通常在不同尺度上呈现不同特征，单一指标无法涵盖完整的失真类型：

### 深度特征感知层

利用深度卷积神经网络的多层级特征映射模拟人类视觉系统。该层对微小的空间亚像素平移、整体轻微色彩偏移具有良好的容忍度，但对高频纹理模糊、语义特征扭曲及异常伪影极为敏感，评估结果最贴近人类主观感知。

### 结构信息统计层

将局部图像区域解耦为亮度对比度、方差离散度与协方差结构相关性。采用 $$11 \times 11$$ 标准高斯滑动窗口遍历整幅图像，针对图像边缘轮廓形变与局部平滑区域退化具有高度敏感度。

### 像素级重构信号层

基于逐像素的均方误差严格计算信号能量比率。当画面发生整体均匀变亮或轻微色偏时，该指标将出现大幅下降，因此为底层数值精度的精确重构提供了客观的底线度量。

```math
\text{PSNR} = 10 \cdot \log_{10}\left(\frac{\text{MAX}^2}{\text{MSE}}\right)

```

## 空间尺寸强校验与快速失败机制

成对保真度指标对空间几何对齐具有极高的严苛要求，本套件实行严格的快速失败策略：

- **禁止隐式插值**：若输入图像与参考图像的宽度或高度不一致（即 $$H_{\text{ref}} \ne H_{\text{gen}}$$ 或 $$W_{\text{ref}} \ne W_{\text{gen}}$$），系统将立即抛出参数异常并终止运行，绝不在底层进行未经声明的双线性插值，杜绝因缩放算法产生的虚假伪影。
- **最小尺寸硬性约束**：结构相似度算法依赖 $$11 \times 11$$ 的高斯滑动窗口。若任意输入图像的宽度或高度小于 11 像素，计算层将直接拦截并报错。
- **输入预处理规范**：若评估不同模型在不同分辨率下的输出，必须在外部调用高质量防混叠抗锯齿降采样算法（如 Lanczos 滤波）对齐至同一基准尺度。

---

## 数值计算协议与聚合逻辑

- **三通道色彩标准化**：无论原始图像为单通道灰度图、红绿蓝三通道图或带透明通道图，系统在加载时均强制统一转换为标准三通道格式。
- **结构相似度多通道平均**：在每个色彩通道上独立应用高斯卷积核计算局部结构相似度，裁剪去除边界填充部分，最终返回三个通道分值的无加权算术均值。
- **目录批处理未加权聚合**：在评估目录时，对所有严格配对成功的样本得分计算算术平均值：
  
  ```math
  \bar{S} = \frac{1}{N} \sum_{i=1}^N S_i
  
  ```

- **极端峰值信噪比无穷大表现**：当某一对图像在数值上完全逐像素重合时，其均方误差为零，该样本信噪比在数学上为正无穷大（`+inf`）。依据既定聚合协议，若目录中存在哪怕一个无穷大样本，全目录计算均值在数学上即收敛至正无穷大。

## 命令行调用指南

<Steps>
  <Step>
    单对图像多维评测。

    同时计算单对图像的感知距离、结构相似度与峰值信噪比：

    ```bash
    image-evaluator --metrics lpips ssim psnr \
        --image path/to/generated.png \
        --reference path/to/reference.png

    ```
  </Step>

  <Step>
    目录批量配对评测。

    对两个目录中同名文件进行成对批处理评测：

    ```bash
    image-evaluator --metrics lpips ssim psnr \
        --image path/to/generated_folder/ \
        --reference path/to/reference_folder/

    ```
  </Step>
</Steps>

## 深入学术细节与实现规范

<Accordions>
  <Accordion title="色彩空间转换与多通道处理">
    读取的所有图像均由张量预处理通道统一归一化至浮点数值区间。感知距离网络接收符合模型要求的规范化输入，结构相似度在浮点格式下以 $$1.0$$ 作为动态极值常数参与稳定分母计算，峰值信噪比将数值上限动态范围严格设定为 $$1.0$$。
  </Accordion>

  <Accordion title="严格文件名配对契约">
    在目录成对评测模式下，系统执行严格的主文件名大小写敏感匹配逻辑（忽略扩展名差异，例如 `case_01.png` 与 `case_01.jpg` 视作有效成对样本）。若参考目录中的某个主文件名在生成目录中未检索到，或反向缺失，系统将立即抛出文件未找到异常中断运行，绝不静默评估部分不完整样本。
  </Accordion>

  <Accordion title="超分辨率与降采样预处理建议">
    在进行超分辨率模型评测时，生成的高清图像必须直接与通过硬件采集或严谨摄影获得的地面真值高清原图进行比对。严禁使用第三方超分辨率重构算法生成的预测图像替代真值；若非理想环境下不得不使用代理参照物，必须在学术成果报告中显式声明其为代理参考对比。
  </Accordion>
