# VQAScore (Visual Question Answering Alignment)

VQAScore by Lin et al. (ECCV 2024) evaluates generative text-to-image synthesis by casting alignment evaluation as visual question answering (VQA). Conventional dual-tower embeddings (such as CLIPScore) project whole scenes and prompts into isolated feature vectors, frequently suffering from "bag-of-words" degradation—ignoring grammatical negation, relative spatial relationships, counting, and multi-attribute binding.

VQAScore overcomes this fundamental limitation by scoring generation through the posterior generation probability that a vision-language model answers **"Yes"** to whether the image depicts the prompt.

## Mathematical Formulation

The evaluation prompt is constructed using the standardized bidirectional query template:

```math
\text{Question: Does this figure show "{prompt}"? Please answer yes or no.}
```

```math
\text{Target Answer: Yes}
```

The evaluation score is computed directly from the sequence cross-entropy loss over the target tokens:

```math
\text{VQAScore}(I, T) = P(\text{"Yes"} \mid I, T) = \exp\left(-\mathcal{L}_{\text{CE}}(\hat{\mathbf{y}}, \mathbf{y}_{\text{"Yes"}})\right)
```

This yields a continuous probability strictly within $[0.0, 1.0]$, where higher values indicate stronger text-image alignment and compositional fidelity.

---

## Non-Equivalence Notice: Calibrated Posterior Probability

`vqascore` is fundamentally distinct from dual-tower cosine similarities and regression rewards:
- **Calibrated Posterior Probability**: Bounded strictly in $[0.0, 1.0]$, representing model likelihood of positive assertion.
- **Compositional Superiority**: Sensitive to spatial prepositions (*left of*, *inside*), counts (*three apples*), and color-object binding (*red cube and blue sphere*).
- **Aspect Ratio Preservation**: `image-evaluator` applies `expand2square` padding with the CLIP preprocessor image mean color prior to resizing, eliminating distortive geometric stretching.

## Usage Examples

<Steps>
  <Step>
    ### Single Image Evaluation

    Evaluate compositional alignment for a complex visual prompt:

    <Tabs items={["CLI Command", "Python API"]}>
      <Tab value="CLI Command">
        ```bash
        image-evaluator --metrics vqascore \
            --image path/to/generated.png \
            --prompt "a red sports car parked in front of a modern glass building"
        ```
      </Tab>
      <Tab value="Python API">
        ```python
        from image_evaluator import evaluate

        scores = evaluate(
            metrics="vqascore",
            image="path/to/generated.png",
            prompt="a red sports car parked in front of a modern glass building",
        )
        print("VQAScore Probability:", scores["vqascore"])
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### Directory Batch Evaluation

    Evaluate arithmetic mean alignment across multiple candidate generations:

    <Tabs items={["CLI Command", "Python API"]}>
      <Tab value="CLI Command">
        ```bash
        image-evaluator --metrics vqascore \
            --image path/to/generated_folder/ \
            --prompt "a silver cup placed on top of a stack of books"
        ```
      </Tab>
      <Tab value="Python API">
        ```python
        from image_evaluator import evaluate_detailed

        result = evaluate_detailed(
            metrics=["vqascore"],
            image="path/to/generated_folder/",
            prompt="a silver cup placed on top of a stack of books",
        )
        print(f"Mean VQAScore: {result['vqascore']:.4f}")
        ```
      </Tab>
    </Tabs>
  </Step>
</Steps>
