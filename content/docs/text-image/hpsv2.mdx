# HPS v2.1 (Human Preference Score)

Human Preference Score v2.1 (HPS v2.1) by Wu et al. (NeurIPS 2023) measures how closely a generated image aligns with human aesthetic judgments and prompt conditioning. Fine-tuned on the Human Preference Dataset v2 (HPD v2) containing 800,000 human pairwise choices across competitive diffusion models, HPS v2.1 provides high correlation with human perceptual rank order.

---

## Technical Specifications

| Property | Specification |
| :--- | :--- |
| **Category** | Human Preference & Text-Image Alignment |
| **CLI Metric** | `hpsv2` |
| **Input Options** | `--image <path>`, `--prompt <string>` (both required) |
| **Prohibited Options** | `--reference` (not applicable for text-to-image prompt evaluation) |
| **Output Scale** | Continuous cosine similarity in `[-1.0, 1.0]` (typical range `[0.20, 0.35]`) |
| **Direction** | **Higher is better** |
| **Model Backbone** | OpenCLIP `ViT-H-14` fine-tuned checkpoint (`HPS_v2.1_compressed.pt`) |
| **Install Extra** | `pip install 'image-evaluator[preference]'` |
| **Upstream Source** | [Wu et al., NeurIPS 2023 (HPSv2)](https://arxiv.org/abs/2306.09341) |

## Mathematical Formulation

HPS v2.1 projects both the visual image and text prompt into a normalized 1024-dimensional joint embedding space using the fine-tuned dual-tower transformer:

```math
S_{\text{HPS}}(I, T) = \frac{\mathbf{v}(I)}{\|\mathbf{v}(I)\|_2} \cdot \frac{\mathbf{t}(T)}{\|\mathbf{t}(T)\|_2}
```

where $\mathbf{v}(I) \in \mathbb{R}^{1024}$ and $\mathbf{t}(T) \in \mathbb{R}^{1024}$ represent the visual and textual representation vectors.

---

## Non-Equivalence Notice: Not Interchangeable with PickScore or ImageReward

`hpsv2` is **not** numerically comparable to other preference or reward models:
- **HPS v2.1**: Computes raw cosine similarity (strictly within `[-1.0, 1.0]`, typically $0.20 \sim 0.35$).
- **PickScore**: Applies an MLP classification head with temperature scaling, yielding positive logits in $[15.0, 25.0]$.
- **ImageReward**: Uses cross-attention and an MLP regression head, producing unbounded continuous scalar reward values centered around zero ($[-2.5, 2.5]$).

## Download Disclosure Policy

The `HPS_v2.1_compressed.pt` checkpoint requires approximately 1.84 GiB of storage. Under toolkit governance rules, uncached weights require explicit opt-in (`--allow-download` via CLI or `allow_download=True` via Python API).

## Usage Examples

<Steps>
  <Step>
    ### Single Image Evaluation

    Score human aesthetic preference for a generated image:

    <Tabs items={["CLI Command", "Python API"]}>
      <Tab value="CLI Command">
        ```bash
        image-evaluator --metrics hpsv2 \
            --image path/to/generated.png \
            --prompt "a majestic snow leopard in high mountain blizzard"
        ```
      </Tab>
      <Tab value="Python API">
        ```python
        from image_evaluator import evaluate

        scores = evaluate(
            metrics="hpsv2",
            image="path/to/generated.png",
            prompt="a majestic snow leopard in high mountain blizzard",
        )
        print("HPS v2.1 Score:", scores["hpsv2"])
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### Directory Batch Evaluation

    Evaluate arithmetic mean preference across a folder of candidate images:

    <Tabs items={["CLI Command", "Python API"]}>
      <Tab value="CLI Command">
        ```bash
        image-evaluator --metrics hpsv2 \
            --image path/to/generated_folder/ \
            --prompt "modern architectural villa with glass facade"
        ```
      </Tab>
      <Tab value="Python API">
        ```python
        from image_evaluator import evaluate_detailed

        result = evaluate_detailed(
            metrics=["hpsv2"],
            image="path/to/generated_folder/",
            prompt="modern architectural villa with glass facade",
        )
        print(f"Mean HPS v2.1: {result['hpsv2']:.4f}")
        ```
      </Tab>
    </Tabs>
  </Step>
</Steps>
