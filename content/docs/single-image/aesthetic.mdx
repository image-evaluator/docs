# 单图美学质量

单图美学质量指标用于量化评估单张图像在人类视觉审美层面的综合质感与构图水平。该指标通过大规模人类审美评分数据集训练线性回归头，赋予模型对生成图像细节质感、色彩和谐度与整体构图美感的感知能力。

---

## 技术规格与基本参数

| 参数维度 | 详细规格说明 |
| :--- | :--- |
| **所属分类** | 感知视觉质量（无参考评估） |
| **命令行标识** | `aesthetic` |
| **输入约束** | `--image`（支持单个图像文件或包含图像的目录路径） |
| **输出形式** | 连续标量浮点数（通常分布于 1.0 至 10.0 区间） |
| **数值导向** | **数值越高越优**（更高分值代表更贴近高质量审美偏好） |
| **主干网络** | OpenCLIP `ViT-L-14`（采用 `openai` 预训练权重，强制启用 `force_quick_gelu=True`） |
| **回归权重** | `sa_0_4_vit_l_14_linear.pth` |
| **参考开源项目** | `LAION-AI/aesthetic-predictor` |

---

## 理论背景与作用机制

单图美学评分基于预训练视觉语言模型的深层表征空间。首先利用在大规模图文对上对比学习预训练的视觉变换器提取图像的多尺度特征，并完成 $$L_2$$ 范数归一化。随后将归一化后的视觉嵌入向量投影至专用的线性回归打分层，输出对图像审美水平的连续标量预测值。

该指标在生成式任务中承担多重关键角色：
- **生成结果质量初筛**：自动过滤结构崩塌、色彩杂乱或视觉构图明显劣化的问题生成样本。
- **提示词工程风格微调**：定量对比不同风格修饰词（如艺术媒介、布光方式、渲染引擎说明）对输出画质的增益效果。
- **模型微调数据清洗**：在微调下游扩散模型前，对训练集进行审美阈值截断以剔除低质训练图像。

---

## 结果解读与评估准则

- **无绝对裁决阈值**：禁止使用固定的绝对截断分值（如一律认为大于 6.0 即为优质）来判定图像优劣。
- **严格控制变量对比**：仅可在完全相同的主干模型结构与预处理输入管道下，对比不同生成模型或采样步数的相对分值高低。
- **与语义指标互补使用**：单图美学高分仅代表视觉构图与色彩质感良好，不代表画面符合文本提示词约束或不存在解剖结构错误。

## 适用范围与局限说明

- **语义无关性**：美学评分无法检验图像是否忠实表达了文本提示词的要求。
- **生物结构盲区**：无法有效检测肢体结构扭曲、手部指节畸变或面部五官不对称等生成式常见缺陷。
- **数据风格偏好偏差**：评分结果受制于原始审美训练集（如人类主观评分数据集）的主观偏好分布，可能对特定小众艺术流派或极简风格存在系统性偏差。

## 深入学术细节与实现规范

<Accordions>
  <Accordion title="激活函数与分值漂移分析">
    本套件在实例化视觉变换器模型时显式传入 `force_quick_gelu=True`：
    
    1. **对齐上游权重与历史实现**：设置 `force_quick_gelu=True` 严格对齐了官方预训练权重及其追溯的历史参考实现。早期版本直接执行对应的快速高斯误差线性单元，而在后续版本中默认回退至标准高斯误差线性单元，这会导致上游权重不匹配警告。强制开启后完全消除了该项警告。
    2. **分值数值漂移**：从标准激活函数切换为对齐的快速激活函数会微调提取出的图像特征向量，在基准测试样本上观察到单图预测分值存在约 -0.20 至 +0.04 的微小漂移。
    3. **可复现性规范**：此项对齐旨在保障模型架构与底层权重严格自洽，消除运行警告，并不代表模型预测精度的绝对升降。
  </Accordion>

  <Accordion title="算法实现与特征提取细节">
    预测器读取图像并转换为三通道标准色彩格式后，由视觉变换器提取 768 维深度表征向量并完成单位范数化：
    
    ```math
    v_{\text{norm}} = \frac{v}{\|v\|_2}
    
    ```
    
    随后计算线性映射打分：
    
    ```math
    \text{Score} = w^T v_{\text{norm}} + b
    
    ```
    
    当输入目标为目录时，扫描所有有效图像格式并计算未加权算术平均数：
    
    ```math
    \mu = \frac{1}{N} \sum_{i=1}^N \text{Score}_i
    
    ```
  </Accordion>
