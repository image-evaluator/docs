# 图像语义相似度

图像语义相似度度量生成图像与参考原图在视觉语义与主体身份层面的一致性。相比于聚焦像素误差的峰值信噪比或局部纹理退化的感知相似度，该指标将两张图像投射至统一的视觉特征空间，通过计算高维表征矢量的归一化余弦相似度来评判主体特征保留程度。

---

## 核心规格

| 属性 | 规范定义 |
| :--- | :--- |
| **评测体系** | 成对视觉语义与主体保真度 |
| **命令行参数** | `--metrics clip_i` |
| **输入要求** | `--image <路径>`, `--reference <路径>` (两项皆必填) |
| **禁止参数** | `--prompt` (成对评测禁止传入文本提示词) |
| **空间约束** | 自动双三次插值缩放并居中裁剪至 $$224 \times 224$$，不强制要求两图原始分辨率一致 |
| **标度范围** | 标量连续浮点数 `[-1.0, 1.0]` (完全相同图像收敛为 1.0000) |
| **取值方向** | **数值越高越优** |
| **模型主干** | 官方架构与权重 |
| **权威源** | [Radford 等, 2021](https://arxiv.org/abs/2103.00020) / [Ruiz 等, 2023](https://arxiv.org/abs/2208.12242) |

---

## 理论公式推导

给定参考图像 $I_{\text{ref}}$ 与生成图像 $I_{\text{gen}}$，通过冻结参数的视觉编码器 $\phi$ 分别提取特征向量并计算余弦相似度：

```math
S_{\text{CLIP-I}}(I_{\text{ref}}, I_{\text{gen}}) = \frac{\phi(I_{\text{ref}})}{\|\phi(I_{\text{ref}})\|_2} \cdot \frac{\phi(I_{\text{gen}})}{\|\phi(I_{\text{gen}})\|_2}
```

其中 $\phi(I) \in \mathbb{R}^{768}$ 为深层视觉投影特征向量。

---

## 模型架构与表征保真

该指标严格绑定官方架构实现，杜绝激活函数错配导致的特征塌缩问题，确保评估结果与学术界评测基准具备严格的数值复现一致性。

---

## 评测建议与场景解读

- **主体保真度量**：广泛应用于个性化生成与指令图像编辑任务中，用于评估生成主体是否维持了参考图像的身份与语义核心。
- **几何与构图容忍度**：由于该指标是在高级语义特征空间衡量距离，生成主体发生合理的姿态、缩放或背景变换时不会产生断崖式惩罚。
- **目录主名配对**：在目录批处理模式下，系统严格依据文件名主名执行跨格式一对一匹配与算术平均。

## 调用示例

<Steps>
  <Step>
    ### 单对图像主体相似度评估

    计算单张生成图片与原图的语义相似度：

    <Tabs items={["命令行 CLI", "Python API 代码"]}>
      <Tab value="命令行 CLI">
        ```bash
        image-evaluator --metrics clip_i \
            --reference path/to/reference.png \
            --image path/to/generated.png
        ```
      </Tab>
      <Tab value="Python API 代码">
        ```python
        from image_evaluator import evaluate

        scores = evaluate(
            metrics="clip_i",
            image="path/to/generated.png",
            reference="path/to/reference.png",
        )
        print("语义相似度:", scores["clip_i"])
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### 目录级成对批处理评估

    对整个文件夹内的生成结果与原图集进行主名配对评测：

    <Tabs items={["命令行 CLI", "Python API 代码"]}>
      <Tab value="命令行 CLI">
        ```bash
        image-evaluator --metrics clip_i \
            --reference path/to/reference_dir/ \
            --image path/to/generated_dir/
        ```
      </Tab>
      <Tab value="Python API 代码">
        ```python
        from image_evaluator import evaluate_detailed

        result = evaluate_detailed(
            metrics=["clip_i"],
            image="path/to/generated_dir/",
            reference="path/to/reference_dir/",
        )
        print(f"均值评分: {result['clip_i']:.4f}")
        ```
      </Tab>
    </Tabs>
  </Step>
</Steps>
