# 结构相似性

结构相似性指数（Structural Similarity Index Measure，简称 SSIM）由 Zhou Wang 等人于 IEEE TIP 2004 提出。SSIM 打破了传统均方误差仅关注像素绝对能量偏差的局限，将图像局部失真解耦为亮度、对比度与结构结构相关性三个物理分量，成为计算机视觉与图像处理领域应用最广泛的结构保真度基准。

---

## 核心规格与指标特性

| 参数维度 | 规范与技术事实 |
| :--- | :--- |
| **命令行参数** | `--metrics ssim` |
| **输入约束** | 必须成对提供 `--image` 与 `--reference`（单图或目录同名配对） |
| **输出形式** | 位于区间 $$[-1.0, 1.0]$$ 的标量浮点数 |
| **数值导向** | **越高越优**（1.0 代表局部结构与对比度完全一致） |
| **加权核规范** | 严格采用标准二维归一化高斯加权核（窗口尺寸 $$11 \times 11$$，方差 $$\sigma=1.5$$） |
| **动态标尺** | 严格限定输入浮点范围 $$[0.0, 1.0]$$ 且动态范围常数 $$L=1.0$$ |
| **学术出处** | Wang et al., "Image Quality Assessment: From Error Visibility to Structural Similarity", IEEE TIP 2004 |

---

## 理论推导与数学形式

设 $$x$$ 与 $$y$$ 为两幅局部图像块，SSIM 将其解耦为三个比较分量：

```math
\text{SSIM}(x, y) = [l(x, y)]^\alpha \cdot [c(x, y)]^\beta \cdot [s(x, y)]^\gamma

```

在经典标准设定下，通常取权重 $$\alpha = \beta = \gamma = 1$$。此时公式可化简为对称乘积形式：

```math
\text{SSIM}(x, y) = \frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)}

```

其中稳定常数定义为：
- $$C_1 = (K_1 L)^2, \quad C_2 = (K_2 L)^2$$（默认 $$K_1=0.01, K_2=0.03$$，$$L$$ 为像素动态范围）；
- 局部均值 $$\mu_x, \mu_y$$、局部方差 $$\sigma_x^2, \sigma_y^2$$ 以及局部协方差 $$\sigma_{xy}$$ 均通过 $$11 \times 11$$ 归一化高斯卷积核滑动加权计算得到。

---

## 边界陷阱与实现准则

- **高斯加权与均匀盒滤波的本质区别**：部分早期工程库错误使用 $$7 \times 7$$ 均匀平权盒式滤波替代高斯滤波，导致局部权重失真并在边缘产生跳变。本套件严格对齐 Wang 2004 原始高斯窗口与反射填充协议，与科学计算标准库 Scikit-Image 保持绝对误差小于 $$3 \times 10^{-7}$$ 的极限对齐。
- **空间最小尺寸限制**：因卷积核尺寸为 $$11 \times 11$$，输入图像的高度与宽度均不得小于 11 像素。若任意维度低于 11 像素，系统将立即抛出异常阻断运行，坚决避免生成非法静默空值。
- **多通道无加权平均**：对红、绿、蓝三个色彩通道分别独立计算全图有效像素的局部均值，最终返回三个通道分数的无加权算术平均值。

## 命令行调用范例

<Steps>
  <Step>
    单对图像评测。

    评估单幅生成图像与参考图的局部结构相似性：

    ```bash
    image-evaluator --metrics ssim \
        --reference path/to/reference.png \
        --image path/to/generated.png

    ```
  </Step>

  <Step>
    目录批量评测。

    对两个目录中的成对文件执行批处理结构评分：

    ```bash
    image-evaluator --metrics ssim \
        --reference path/to/reference_folder/ \
        --image path/to/generated_folder/

    ```
  </Step>
</Steps>

## 深入工程细节与诊断建议

<Accordions>
  <Accordion title="为什么动态范围参数设定至关重要">
    当图像归一化至浮点 $$[0.0, 1.0]$$ 时，常数 $$C_1, C_2$$ 必须基于 $$L=1.0$$ 计算（$$C_1=0.0001, C_2=0.0009$$）。若错误沿用整数尺度 $$L=255$$，稳定常数将膨胀上万倍，导致公式退化为主导常数比值，测算出的结构分数将虚高失效。
  </Accordion>

  <Accordion title="结构相似性在局部模糊与伪影检测中的价值">
    SSIM 对局部高频纹理平滑、涂抹与边缘形变高度敏感，能够精准反映超分辨率模型在细节生成中的局部退化。与 LPIPS 结合使用，能够兼顾深层语义感知与浅层局部像素结构的一致性。
  </Accordion>
</Accordions>
