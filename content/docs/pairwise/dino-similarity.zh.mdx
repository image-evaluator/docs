# 自监督结构相似度

自监督结构相似度利用无需文本标签标注的自监督视觉变换器模型，衡量图像之间的结构布局与视觉表征一致性。由于自监督预训练过程直接从图像像素与几何掩码中学习表征，该指标对物体空间形变、视角畸变以及边缘轮廓的保留程度具有极高的敏感度。

---

## 核心规格

| 属性 | 规范定义 |
| :--- | :--- |
| **评测体系** | 成对视觉语义与结构保真度 |
| **命令行参数** | `--metrics dino_similarity` |
| **输入要求** | `--image <路径>`, `--reference <路径>` (两项皆必填) |
| **禁止参数** | `--prompt` (成对评测禁止传入文本提示词) |
| **空间约束** | 自动双三次插值缩放并居中裁剪至 $$224 \times 224$$，不强制要求两图原始分辨率一致 |
| **标度范围** | 标量连续浮点数 `[-1.0, 1.0]` (完全相同图像收敛为 1.0000) |
| **取值方向** | **数值越高越优** |
| **模型主干** | 基础视觉变换器模型架构 |
| **权威源** | [Oquab 等, 2023](https://arxiv.org/abs/2304.07193) |

---

## 理论公式推导

给定参考图像 $I_{\text{ref}}$ 与生成图像 $I_{\text{gen}}$，通过模型提取末层全局类别标记特征向量并计算余弦相似度：

```math
S_{\text{DINO}}(I_{\text{ref}}, I_{\text{gen}}) = \frac{\mathbf{z}_{\text{cls}}(I_{\text{ref}})}{\|\mathbf{z}_{\text{cls}}(I_{\text{ref}})\|_2} \cdot \frac{\mathbf{z}_{\text{cls}}(I_{\text{gen}})}{\|\mathbf{z}_{\text{cls}}(I_{\text{gen}})\|_2}
```

其中 $\mathbf{z}_{\text{cls}}(I) \in \mathbb{R}^{768}$ 为经过归一化的全局结构特征向量。

---

## 概念界定与非等价性声明

通用的余弦相似度度量与特定基准测试套件中的结构距离存在本质区别：
- **基准结构距离**：通常抽取深层自注意力分布矩阵差异，或依赖局部前景掩码进行加权截取。
- **核心库原生指标**：针对全图视觉表征计算全局类别标记余弦相似度，提供通用的布局保真参考。

---

## 评测建议与场景解读

- **几何结构敏感度**：在指令编辑任务中，能够精确反映非编辑区域是否发生意外的结构坍塌或空间位移。
- **纯视觉表征优势**：不受文本分词器偏置影响，适合作为文本对齐指标的几何维度补充。
- **目录主名配对**：在目录批处理模式下，系统严格依据文件名主名执行跨格式一对一匹配与算术平均。

## 调用示例

<Steps>
  <Step>
    ### 单对图像结构相似度评估

    评估编辑图像与原图之间的结构保持程度：

    <Tabs items={["命令行 CLI", "Python API 代码"]}>
      <Tab value="命令行 CLI">
        ```bash
        image-evaluator --metrics dino_similarity \
            --reference path/to/reference.png \
            --image path/to/generated.png
        ```
      </Tab>
      <Tab value="Python API 代码">
        ```python
        from image_evaluator import evaluate

        scores = evaluate(
            metrics="dino_similarity",
            image="path/to/generated.png",
            reference="path/to/reference.png",
        )
        print("结构相似度:", scores["dino_similarity"])
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### 目录级成对批处理评估

    批量评估生成目录与参考目录中同名图对的结构均值：

    <Tabs items={["命令行 CLI", "Python API 代码"]}>
      <Tab value="命令行 CLI">
        ```bash
        image-evaluator --metrics dino_similarity \
            --reference path/to/reference_dir/ \
            --image path/to/generated_dir/
        ```
      </Tab>
      <Tab value="Python API 代码">
        ```python
        from image_evaluator import evaluate_detailed

        result = evaluate_detailed(
            metrics=["dino_similarity"],
            image="path/to/generated_dir/",
            reference="path/to/reference_dir/",
        )
        print(f"均值结构分值: {result['dino_similarity']:.4f}")
        ```
      </Tab>
    </Tabs>
  </Step>
