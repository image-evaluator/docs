# 核最大均值差异

核起始距离（Kernel Inception Distance，简称 KID）由 Mikołaj Bińkowski 等人于 ICLR 2018 提出，旨在克服弗雷歇距离（FID）严重依赖高斯分布强假设以及在小样本量下存在严重正向经验偏差的理论缺陷。KID 引入再生核希尔伯特空间（RKHS）下的最大均值差异（MMD）理论，利用无偏统计估计量，成为中小规模样本集与特定领域生成评测的首选方案。

---

## 核心规格与指标特性

| 参数维度 | 规范与技术事实 |
| :--- | :--- |
| **命令行参数** | `--metrics kid` |
| **输入约束** | `--reference <dir>` 与 `--image <dir>` 必须同时提供且**均严格要求为已有目录** |
| **输出形式** | 位于实数区间 $$(-\infty, +\infty)$$ 的标量浮点数（通常在 0.0 附近） |
| **数值导向** | **越低越优**（0.0 代表核特征空间两分布完全一致） |
| **核函数形式** | 三次多项式核函数 $$k(x, y) = \left(\frac{1}{d} x^T y + 1\right)^3$$，其中维度 $$d = 2048$$ |
| **统计估计量** | 严格采用无偏 U 统计量（Unbiased U-statistic），允许微弱负值 |
| **可复现协议** | 默认固定随机种子 `seed=0`，严格执行全局随机状态隔离保存与恢复 |
| **学术出处** | Bińkowski et al., "Demystifying MMD GANs", ICLR 2018 |

---

## 理论推导与无偏估计机制

设真实样本特征向量为 $$x \sim \mathbb{P}_r$$，生成样本特征向量为 $$y \sim \mathbb{P}_g$$。最大均值差异的平方可展开为样本点对核函数的期望：

```math
\text{MMD}^2(\mathbb{P}_r, \mathbb{P}_g) = \mathbb{E}[k(x, x')] + \mathbb{E}[k(y, y')] - 2\mathbb{E}[k(x, y)]

```

为了在有限离散样本集（大小分别为 $$m$$ 和 $$n$$）上实现**无偏估计**，Bińkowski 等人采用两两排除自身内积的无偏 U 统计量构造评估函数：

```math
\text{KID} = \frac{1}{m(m-1)} \sum_{i=1}^m \sum_{j \ne i}^m k(x_i, x_j) + \frac{1}{n(n-1)} \sum_{i=1}^n \sum_{j \ne i}^n k(y_i, y_j) - \frac{2}{mn} \sum_{i=1}^m \sum_{j=1}^n k(x_i, y_j)

```

---

## 为什么核最大均值差异适合小样本评估

1. **零经验系统偏差**：FID 在样本较少时会因样本协方差的经验估计而产生不可忽视的正偏差（即同一分布自我采样抽检也会呈现明显大于 0 的数值）。KID 的数学期望严格等于真实总体的最大均值差异平方，在小样本（如 $$N < 1000$$）下依然具备可靠的均值无偏性。
2. **免高斯分布假设**：KID 仅依赖多项式核函数在非线性高维空间中的内积映射，不需要将潜在特征强制拟合为多元正态分布，对复杂的多模态分布具有更强的鲁棒性。

---

## 负数结果的数学合规性与确定性协议

- **微小负值的数学必然性**：由于 KID 是无偏估计量，当真实生成模型极其优秀（两分布近乎完全重合，真值趋近于 0）或采样存在随机浮动时，估计量围绕 0 点呈现正态对称波动，因此出现微弱的负值（如 `-0.001`）是**统计学完全合规的正常表现**。若人为将其硬截断为 0，反而会引入非零估计偏差。
- **确定性种子状态隔离**：KID 在计算过程中涉及随机子集采样。本套件在执行前后严格通过环境上下文管理器记录并还原全局随机状态，固定 `seed=0`，确保多次运行结果在比特级完全一致。

## 命令行调用范例

<Steps>
  <Step>
    单指标数据集评估。

    计算生成目录与基准真实目录之间的核最大均值差异：

    ```bash
    image-evaluator --metrics kid \
        --reference path/to/real_dataset/ \
        --image path/to/generated_dataset/

    ```
  </Step>

  <Step>
    双分布指标联合调用。

    同时计算宏观高斯分布差异（FID）与无偏多项式核差异（KID）：

    ```bash
    image-evaluator --metrics fid kid \
        --reference path/to/real_dataset/ \
        --image path/to/generated_dataset/

    ```
  </Step>
</Steps>
