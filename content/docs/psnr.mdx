# 峰值信噪比

峰值信噪比（Peak Signal-to-Noise Ratio，简称 PSNR）是数字图像处理、有损压缩编解码与底层图像重建任务中最经典、应用最广泛的客观工程评估标准。该指标通过计算最大可能信号功率与影响保真度的重构噪声功率之间的对数比率，以分贝（dB）为单位直观量化像素级的绝对重建质量。

---

## 核心规格与指标特性

| 参数维度 | 规范与技术事实 |
| :--- | :--- |
| **命令行参数** | `--metrics psnr` |
| **输入约束** | 必须成对提供 `--image` 与 `--reference`（单图或目录同名配对） |
| **输出形式** | 标量浮点数，单位为分贝（dB），区间为 $$[0.0, +\infty)$$ |
| **数值导向** | **越高越优**（数值越大代表重构噪声功率越小，$$+\infty$$ 代表像素完全重合） |
| **基准精度** | 与标准科学计算库 Scikit-Image 保持绝对误差小于 $$10^{-5}\text{ dB}$$ 极限对齐 |
| **数据范围** | 输入浮点图像张量严格限定在 $$[0.0, 1.0]$$，对应最大信号幅值 $$\text{MAX} = 1.0$$ |
| **计算类型** | 经典底层无参数逐像素均方误差映射 |

---

## 理论推导与数学形式

对于尺寸同为 $$H \times W$$、具有 $$C$$ 个色彩通道的两幅图像 $$I_{\text{ref}}$$ 与 $$I_{\text{gen}}$$，首先计算全图通道与像素维度的均方误差（Mean Squared Error）：

```math
\text{MSE} = \frac{1}{C \cdot H \cdot W} \sum_{c=1}^C \sum_{h=1}^H \sum_{w=1}^W \left( I_{\text{ref}}(c, h, w) - I_{\text{gen}}(c, h, w) \right)^2

```

峰值信噪比定义为最大信号功率相对于均方误差的以 10 为底的对数比例：

```math
\text{PSNR} = 10 \cdot \log_{10}\left( \frac{\text{MAX}_I^2}{\text{MSE}} \right) = 20 \cdot \log_{10}\left( \frac{\text{MAX}_I}{\sqrt{\text{MSE}}} \right)

```

在浮点归一化图像格式下，$$\text{MAX}_I = 1.0$$，因此计算式可简化为：

```math
\text{PSNR} = -10 \cdot \log_{10}(\text{MSE})

```

## 边界行为与特殊情形处理

- **绝对相同样本的无穷大处理**：当生成图像与参考图像在所有通道所有像素上完全数值一致时，$$\text{MSE} = 0$$。系统在数学上严格返回正无穷大（`inf`），绝不人为引入微小偏置项（如 `eps=1e-10`）导致失准。
- **全目录均值收敛行为**：在目录批处理模式下，由于各样本分数进行算术平均，若目录中存在任意一个逐像素完全匹配的样本（即存在一个 `inf`），全目录计算平均值在数学上即直接收敛为 `inf`。
- **空间几何强对齐约束**：成对图像的高度和宽度必须严格一致。若尺寸失配，系统执行快速失败拦截，要求先通过上采样或下采样算法完成尺度对齐。

## 命令行调用范例

<Steps>
  <Step>
    单对图像评测。

    计算单幅生成图像相对于参考原图的峰值信噪比：

    ```bash
    image-evaluator --metrics psnr \
        --reference path/to/reference.png \
        --image path/to/generated.png

    ```
  </Step>

  <Step>
    目录批量评测。

    对两个目录中同名文件执行逐对信噪比测算并统计均值：

    ```bash
    image-evaluator --metrics psnr \
        --reference path/to/reference_folder/ \
        --image path/to/generated_folder/

    ```
  </Step>
</Steps>

## 深入工程细节与诊断建议

<Accordions>
  <Accordion title="为什么整体微小色偏会导致峰值信噪比暴跌">
    PSNR 基于点对点像素均方误差累加。若画面发生轻微的全局曝光抬升或整体色调偏移，虽然画面的边缘几何、拓扑轮廓与语义结构毫无受损，但每个像素点均产生固定残差并平方累加，导致 MSE 急剧增大，PSNR 显著跌破 20 dB 警戒线。
  </Accordion>

  <Accordion title="信噪比分贝数值的工程参考基线">
    在传统图像压缩与重建评估中：
    - 大于 35 dB：人眼通常极难觉察到与原图的区别；
    - 30 dB ~ 35 dB：质量优良，失真处于可接受范畴；
    - 20 dB ~ 30 dB：肉眼可辨别出一定程度的画质退化与压缩伪影；
    - 低于 20 dB：表明存在明显的整体色阶偏移、严重模糊或大面积结构形变。
  </Accordion>
</Accordions>
