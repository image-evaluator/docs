# 数据集分布评估

数据集分布评估指标面向生成对抗网络、扩散模型以及自回归视觉生成算法，用于衡量生成图像集合在宏观特征空间中与真实图像分布的逼近程度。本套件集成并规范化了业界最具影响力的两项分布距离度量：基于多维高斯假定的弗雷歇感知距离，以及基于非参数核方法与极大均值差异的核感知距离。

## 理论背景与统计学原理

### 弗雷歇距离二阶统计理论

该距离度量两个连续概率分布之间的瓦瑟斯坦距离。在特征提取器将高维像素投影至 2048 维嵌入空间后，假定特征向量服从高维多元正态分布，通过经验均值向量与经验协方差矩阵计算几何距离：

```math
d_{\text{FID}}^2((\mu_r, \Sigma_r), (\mu_g, \Sigma_g)) = \|\mu_r - \mu_g\|_2^2 + \text{Tr}\left(\Sigma_r + \Sigma_g - 2(\Sigma_r \Sigma_g)^{1/2}\right)

```

其中 $$(\mu_r, \Sigma_r)$$ 和 $$(\mu_g, \Sigma_g)$$ 分别代表参考数据集与生成数据集的经验均值向量和经验协方差矩阵。

### 核感知距离无偏估计理论

核感知距离摆脱了高斯正态分布假设，通过在重现核希尔伯特空间中定义的三次多项式核函数计算极大均值差异：

```math
k(x, y) = \left(\frac{1}{d} x^T y + 1\right)^3, \quad d = 2048

```

给定参考集样本特征 $$X$$ 与生成集样本特征 $$Y$$，采用最小方差无偏统计量进行估计：

```math
\text{MMD}_u^2(X, Y) = \frac{1}{m(m-1)} \sum_{i=1}^m \sum_{j \ne i}^m k(x_i, x_j) + \frac{1}{m(m-1)} \sum_{i=1}^m \sum_{j \ne i}^m k(y_i, y_j) - \frac{2}{m^2} \sum_{i=1}^m \sum_{j=1}^m k(x_i, y_j)

```

## 指标特性对比与选型准则

- **大样本通用标杆**：在具有充裕计算资源与大规模测试样本（$$N \ge 50,000$$）的场景下，弗雷歇距离具备最广泛的学术文献可比性。
- **中小样本无偏度量**：在中小规模评估集（$$N < 2,048$$）场景下，弗雷歇距离存在显著的正向统计偏差，而核感知距离在任意样本量（$$N \ge 2$$）下均保持严格无偏性，评估结果更加真实可信。
- **高阶模态捕获**：核感知距离借助三次多项式核能够感知高阶多模态分布漂移，对模式崩塌与多样性缺失更为敏感。

## 目录角色与输入验证契约

- **语义角色绑定**：`--reference` 严格指代真实参考图像目录，`--image` 严格指代待评测生成图像目录。
- **强制目录校验**：双方参数必须为已存在的目录路径。向任一参数传递单文件路径均会被解析层立即拦截并报错。
- **无须文件名匹配**：分布指标评估总体统计属性，两端目录的文件名无须对应，样本数量允许完全不对等（即 $$N_{\text{ref}} \ne N_{\text{gen}}$$）。
- **递归扫描与支持格式**：递归遍历目录及所有子目录，全面支持 10 种常见图像格式（`.bmp`、`.jpg`、`.jpeg`、`.pgm`、`.png`、`.ppm`、`.tif`、`.tiff`、`.webp`、`.npy`）。
- **图片完整性校验**：提取特征前逐一校验文件可读性，杜绝损坏文件或空文件静默退化导致样本漏计。

---

## 样本量敏感度与统计特性

- **最小数学边界**：协方差矩阵与无偏统计量分母均要求两端目录各自至少包含 2 张有效图片（$$N \ge 2$$）。
- **小样本敏感度告警**：当样本总数低于 2048 时，系统将输出警告提示，并在结果中完整记录实际样本量以供审计。
- **审计元数据输出**：终端打印不仅包含最终浮点分值，还自动附带后端库版本、执行模式、提取模型、计算硬件设备与样本统计量。

## 命令行调用指南

<Steps>
  <Step>
    独立评测范式。

    同时运行分布评估指标，量化两个目录之间的分布差异：

    ```bash
    image-evaluator --metrics fid kid \
        --reference path/to/real_dataset/ \
        --image path/to/generated_dataset/

    ```
  </Step>

  <Step>
    联合多维评测。

    将分布指标与成对保真度指标联合调用（成对指标要求两端目录具备同名配对文件，分布指标则独立完成总体评估）：

    ```bash
    image-evaluator --metrics fid kid lpips ssim psnr \
        --reference path/to/paired_reference_dir/ \
        --image path/to/paired_generated_dir/

    ```
  </Step>
</Steps>

## 深入学术细节与可复现性保障

<Accordions>
  <Accordion title="重采样混叠效应与防失真机制">
    传统评估管道在将高分辨率图像下采样至网络输入尺寸（$$299 \times 299$$）时，若缺少平滑低通滤波，高频几何噪声会混叠折叠进低频段，严重污染特征表征。本实现统一锁定为官方双线性抗混叠防失真重采样协议，消除不同底层图形库引起的评测漂移。
  </Accordion>

  <Accordion title="确定性随机种子与全局状态隔离">
    核感知距离在计算过程中执行 100 次子集随机抽样。为确保科学实验的可复现性，系统将随机种子硬性锚定为零，保证多次执行得到完全一致的分值。同时在抽样前后通过保护块保存并恢复全局随机状态，避免对用户其他随机过程产生非预期干扰。
  </Accordion>

  <Accordion title="有限负值统计学原理与完整性保持">
    由于极大均值差异无偏估计量是对非负真实参数的统计估计，在有限样本量且生成分布与真实分布极其接近时，根据对称统计波动原理，估算值有大约一半的概率落在零点左侧微小负区间。人为将其截断为零将彻底破坏统计无偏性并引入系统性正偏差，因此系统严格保留真实的有限浮点数值。
  </Accordion>

  <Accordion title="审计元数据规范与输出格式">
    每次执行后终端以审计元数据格式输出执行明细：
    
    ```text
    FID: 12.345678 (backend=clean-fid, version=0.1.35, mode=clean, model=inception_v3, device=cpu, Nref=1000, Ngen=1000)
    KID: -0.001234 (backend=clean-fid, version=0.1.35, mode=clean, model=inception_v3, device=cpu, num_subsets=100, max_subset_size=1000, seed=0, Nref=1000, Ngen=1000)
    
    ```
  </Accordion>
